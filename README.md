# 拈花 BloomSense · 手势生花

一套由真实手部动作驱动的实时 3D 花卉交互系统，包含两种可以随时切换的花境：

- **实景 · 3DGS**（默认）：用 3D Gaussian Splatting 整帧重建真实花野、春日盆景与石径庭院，花与它的背景一起来自真实扫描；
- **花境 · 互动**：六种由 Blender 程序化生长的花卉，可用手势完成绽放、收拢、换花、换境与 X/Y/Z 三轴旋转。

摄像头画面在浏览器本地由 MediaPipe Gesture Recognizer 分析。参考你提供的真人手势片段（未打包进项目），采用**张开手掌、握拳、单指、双指**等手势作为核心交互语言。

## 快速开始

环境要求：Node.js 20+，Chrome / Edge（摄像头与 WebGL2）。

```bash
npm install
npm run dev
```

打开 **http://localhost:5179**，点击「开启摄像头」并允许浏览器使用摄像头。

「实景 · 3DGS」需要 `public/splats/` 下的三个压缩点云（已随项目提供）：

| 场景 | 文件 | 高斯点 | 说明 |
| --- | --- | ---: | --- |
| 烬红花野 | `flowers_clean.spz` | 3.47M | 美人蕉与朱蕉花野，含背景树林与草地 |
| 春枝盆景 | `bonsai.spz` | 1.24M | 室内盆景与粉色花枝，保留房间背景 |
| 石径庭院 | `garden.spz` | 4.39M | 石径、苔草与庭院植物 |

首次切换场景会下载并解码对应 `.spz`；进度会显示在屏幕中央，之后同一会话内会复用。若只是体验交互花谱，可点击顶部「花境 · 互动」，无需等待点云。

```bash
npm run build     # 生产构建
npm run preview   # 预览生产构建（默认 4173）
```

### 摄像头说明

- 摄像头必须在 **localhost** 或 **HTTPS** 下使用；通过局域网 IP 的纯 HTTP 打开时浏览器会拒绝摄像头。
- 如果看到「摄像头被其他应用占用」，请先关闭正在使用摄像头的会议、录制或相机程序，再点击右上角的「开启摄像头」。
- 如果摄像头不可用，应用会给出明确提示，并可进入「仅浏览花境」模式；UI、鼠标、键盘、花谱、环境切换与三轴控制仍可正常使用。项目不再包含任何演示视频文件。
- 视频帧只在本地浏览器中解析，不会上传。

## 交互方式

### 实景 · 3DGS 模式

- **左键拖拽**：以主体为球心**自由环绕**——水平 360°、俯仰 ±77°，可飞到花圃正上方俯视整圈同心花纹，也可绕到盆景背面；镜头始终 lookAt 主体，位置与朝向一致；
- **右键 / 中键 / Shift+拖拽**：平移视点，自由查看整个场景的任意区域；
- **滚轮 / 触屏双指捏合**：推拉镜头（环绕半径 0.25–6×）；
- **自动巡游（A / 自动旋转）**：镜头绕主体缓慢水平环绕；
- **双击**：一键回到初始扫描机位；
- **开掌 / 握拳**：沿视线微调推近 / 拉远；
- **倾斜手掌 / 捏合拖转**：对当前扫描位做小幅俯仰、偏航、翻转偏移，用来观察花瓣与背景的视差；
- **鼠标拖拽 / 滚轮**：同样可以轻推视角与推近拉远，双击回到初始扫描位；
- **☝ 单指向上**：回到该场景的初始扫描位；
- **✌ 双指 / 👍 点赞 / 👎 点踩**：切换上一处 / 下一处实景；
- **`1–3` 或 `Q W E`**：切换实景；
- **`V`**：在「实景 · 3DGS」与「花境 · 互动」之间切换。

视角采用带**仰角地板**的轨道相机：镜头永远从上方俯视主体，避免绕进花圃四周的草丛或地面产生伪影。3DGS 是静态光场重建，**没有可独立形变的花瓣骨骼**，因此「绽放 / 收拢」只在数字花境模式中可用；实景模式提供真正的自由环绕、平移与缩放来观察真实扫描。

### 花境 · 互动模式

| 手势 | 实时指令 | 行为 |
| --- | --- | --- |
| ✋ 张开手掌 | 花朵绽放 | 按手掌开合度连续控制盛开程度 |
| ✊ 轻轻握拳 | 花朵合拢 | 花瓣缓慢收拢到含苞 |
| ✌ 双指如剪 | 切换花型 | 保持约 0.7 秒，散出花瓣并换到下一朵花 |
| 👍 点赞 | 切换花境 | 保持约 0.7 秒，进入下一重环境 |
| ☝ 单指向上 | 旋转归位 | 保持约 0.8 秒，花朵回到正面；手势模式期间自由旋转锁定 |
| 🖐 倾斜/翻转手掌 | X·Y·Z 微调 | 手掌左右、上下、手腕翻转映射到三轴 |
| 🤏 两指 / 五指捏合 | 拖转整支花 | 捏合后移动手掌，花朵像被握住一样转到新角度；松开后保持，单指向上归零 |

UI 会实时显示 **识别手势 → 对应命令、置信度、FPS、推理延迟**，并可在左侧「姿态轴」锁定任意轴或手动输入角度。

### 操控偏好（设置 · 操控习惯）

拖拽、手势、键盘、触屏四条输入通路始终同时可用，并按习惯微调：

- **拖拽 / 滚轮灵敏度**（0.3–2.0×）：鼠标、触控板、触屏巡游机位与推拉的速度；
- **手势灵敏度**（0.3–2.0×）：手幅小、离摄像头远的用户调高，容易误触的用户调低；倾斜与捏合共用同一增益；
- **反转俯仰轴**：习惯飞行模拟器式"上推=抬头"的用户开启，作用于手势与拖拽；
- **减弱动效**：关闭自动巡游、常驻呼吸摆动与基座浮沉，照顾晕动症与前庭敏感用户；
- 开合幅度沿用**自适应标定**，每位用户的手掌大小与距离都会自动学习，无需手动校准；
- 无摄像头 / 摄像头被占用时自动降级为键盘 + 鼠标 + 触屏全功能浏览（`Space` 开合、`← →` 巡游、`↑ ↓` 俯仰、`1–3` 换景、`V` 换模式）。

### 键盘快捷键

`V` 切换实景 / 花境 · `1–6` 换花 · `Q W E R T Y U` 换境（实景模式下 `1–3` / `Q W E` 换实景） · `Space` 开合或推近 · `A` 自动旋转（手势模式下锁定） · `O` 自动巡游 · `X Y Z` 锁定轴 · `↑↓←→` 微调旋转 · `G` 手势指南 · `L` 花谱 · `S` 设置 · `M` 声音 · `H` 隐藏界面 · `F` 全屏 · `Esc` 关闭面板。

鼠标拖拽环绕、滚轮缩放；「隐藏界面」只留下花与花境。

## 视觉与交互系统

### 实景 · 3DGS

三个场景由官方 3D Gaussian Splatting 预训练模型转换而来。原始 `.ply` 经过 NaN 清理、浮尘过滤与球体裁剪后压缩为 `.spz`；运行时通过 Spark（`@sparkjsdev/spark`）直接渲染，不经过 EffectComposer，以保留扫描的颜色与光。

- 每个场景的相机位从训练用的 `cameras.json` 中挑选，避免走出训练视角产生漂浮伪影；
- 默认相机是选定扫描位，叠加极轻的呼吸位移与（关闭手势时才启用的）微幅漂移；每个场景带独立曝光补偿（盆景室内 +42%，庭院 +20%），保证暗部细节可见；
- 切换场景时保留上一帧直到新点云可用，避免闪黑；加载进度显示在屏幕中央；
- 扫描数据仅用于技术样例，许可与署名见 [ATTRIBUTIONS.md](./ATTRIBUTIONS.md)。

### 六种花 · 花谱

玫瑰、莲花、百合、郁金香、樱花、雏菊。每种花包含独立的：

- 分层花瓣生长参数（玫瑰 26 瓣 / 30 枚可动雄蕊，莲花 24 瓣与莲蓬，百合 6 瓣与 6 枚雄蕊，等）；
- 6 个烘焙开花形态关键帧，运行时按任意开花度插值；
- 花瓣 UV、瓣脉、边缘皱褶、细密表面起伏、真实花托与萼片；
- 独立 GLB 模型与透明 PNG 花谱预览。

### 动态特效（与生命周期同步）

- **花瓣着色器**：UV 驱动的瓣脉、微表面斑纹、菲涅尔绒光与透光；随花开度逐渐暖化，并叠加手势/换花触发的脉冲色。
- **生命花粉**：花心周围 120 个粒子随花开度升起、变亮；手势存在时能量增强。
- **生命光环**：基座上的光环随花开度扩张，切换花型/花境时产生脉冲。
- **换花**：花瓣粒子爆发 + 扩散光环 + 花瓣着色器脉冲 + 环境瞬闪。
- **环境**：七重花境（晨光花室、雾竹幽庭、月下镜湖、星穹花庭、晨曦云海、琥珀秋苑、极光冰原），每重环境都有手写 GLSL 天空/水面/极光/云海/苔地/粒子；雾竹幽庭含程序化竹节、竹叶、石灯与体积光柱，琥珀秋苑含分形枝干、飘落叶片与暖雾；切换时以雾幕过渡。
- **后处理**：Bloom、暗角、胶片颗粒、细微色差；随花开度微调整体色温与曝光，动作时叠加暖色脉冲。

### 机器学习手势管线

1. **MediaPipe Gesture Recognizer** 在浏览器内对视频帧做推理，输出 21 个手部关键点与预训练手势类别（GPU delegate，失败自动回退 CPU）。
2. **几何融合层**：当 CNN 置信度不足时，用手指伸展状态恢复张掌/握拳/双指/单指，提升侧脸、背光下的稳定性。
3. **自适应标定**：持续学习用户自己的张开/握拳范围，把连续开合映射到 0–1，而不是依赖固定阈值。
4. **时间平滑与迟滞**：EMA 平滑、保持计时、动作冷却，避免抖动和误触发；实时显示 FPS 与推理延迟。
5. **手掌姿态 → 三轴旋转**：掌心的左右、上下和手腕翻转，经过平滑与轴锁定，映射到花朵的 Y/X/Z 旋转。

### 三轴与图库

- 左侧姿态轴面板支持 X/Y/Z 手动角度、轴锁定、归零与自动自转。
- 花谱图库支持缩略图切换、完整六花总览、每朵花的诗句和拉丁名。
- 七种花境可从右侧选择，或开启每 42 秒自动巡游。

## Blender 模型

模型由 `blender/build_flowers.py` 程序化生成：每片花瓣在独立方位楔形内生长，花瓣基部嵌入花托，开花使用 6 个烘焙形态键；雄蕊随开花逐步伸出。

```bash
blender -b --factory-startup -P blender/build_flowers.py -- --no-render
```

可打开 `blender/flowers_master.blend` 查看全部模型；`blender/verify/` 包含各花在闭合/半开/全开状态的检查渲染。

**穿模校验**：对每一朵花，在 19 个插值开花阶段对所有花瓣/雄蕊做 BVH 三角面相交检测。最终报告 `blender/verification_report.json` 与 `verification_summary.txt` 显示六种花的结果均为 **0 个可见相交**（花托内部接合部不计；这是有意嵌入的连接结构）。

| 花型 | 花瓣 | 雄蕊 | 顶点 | GLB | 可见相交 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 玫瑰 | 26 | 30 | 12,604 | 2.19 MB | 0 |
| 莲花 | 24 | 0（莲蓬） | 5,427 | 0.86 MB | 0 |
| 百合 | 6 | 6 | 2,778 | 0.39 MB | 0 |
| 郁金香 | 6 | 6 | 2,750 | 0.39 MB | 0 |
| 樱花 | 5 | 16 | 3,599 | 0.52 MB | 0 |
| 雏菊 | 32 | 0（花盘） | 5,266 | 0.60 MB | 0 |

### 关于花心亮度

早期版本使用花心点光与附加光晕，导致高光溢出。当前版本已移除花心补光与全屏光晕，降低曝光与 Bloom 阈值，并改用柔和台灯式照明；同时给玫瑰增加了 30 枚真实金色雄蕊和深色花托，因此中心结构在浅色花室中可见而不是一团白。

## 已知边界

- 3DGS 是静态光场重建，不能像骨骼模型那样让每一片花瓣独立张开；实景模式因此不做花朵绽放形变，只做推近/拉远与轻微视角偏移。可交互的绽放仍在「花境 · 互动」中。
- 3DGS 模型来自公开研究样例，适用研究/非商业许可；商业使用请替换为自有扫描资产，详见 [ATTRIBUTIONS.md](./ATTRIBUTIONS.md)。单个场景 28–90 MB，首次载入需要数秒，画质优先。
- 六种花是程序化艺术化模型，强调可交互的分层生长与完整结构，不追求照片扫描级写实；细节集中在瓣脉、皱褶、雄蕊与花托。写实需求由 3DGS 模式承担。
- MediaPipe 的部分图操作由 CPU/XNNPACK 执行；在低端机器上可切换「平衡」画质或关闭摄像头使用 UI 控制。
- 声音默认关闭，点击右上角音量图标启用；生成式环境声不依赖音频文件。
- 若摄像头被占用，必须由用户释放占用程序；应用会显示具体提示；也可以先用「仅浏览花境」模式操作界面。
